# data/

Everything in this directory is git-ignored except this README and the `.gitkeep`
placeholder files.

- `source/`: put the manually downloaded NYC Open Data CSV files here. The
  pipeline only reads them; it never modifies them. See the main README for the
  expected filename patterns.
- `bronze/`: generated by the pipeline: `<dataset>/snapshots/<snapshot_id>/`
  (Parquet + `manifest.json`) and `<dataset>/latest.json`. Do not edit files here
  by hand.
